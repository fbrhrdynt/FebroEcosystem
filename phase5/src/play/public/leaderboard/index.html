03 / HOW IT WORKS

GIMANA SKOR
MASUK KE SINI?

01

Tekan Play

Game meminta tiket ronde dari server. Satu tiket hanya berlaku untuk satu ronde.

02

Selesaikan ronde

SKYHOP mencatat koin saat finis; Snake mencatat poin saat game over; Orbit mencatat jarak saat nyawa habis. Hoof Hustle mencatat jarak terbaik saat jatuh, sedangkan Octo Ascent mencatat tinggi terbaik setiap percobaan. Tidak ada timer atau balapan.

03

Skor diverifikasi dasar

Server mengecek tiket, durasi, dan batas skor masuk akal. Skor terbaik ditampilkan dalam peringkat per game dan mode.

Catatan: leaderboard menggunakan pengecekan anti-cheat dasar, belum verifikasi replay/server-authoritative. Tidak ada peringkat publik untuk GhaffiLand karena ditujukan bagi anak-anak. Tidak perlu mengisi nama lengkap atau data anak.
