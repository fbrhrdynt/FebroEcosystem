# v2.0.0 — 12 October 2026

- Replaces un-deployed v1.0.0 (not a partial patch).
- Ten virtual host apps in one Node.js runtime.
- Email registration/login, mailbox verification, reset password with branded Hostinger SMTP HTML messages.
- Google OAuth 2.0 authorization code / PKCE, verified server-side ID token, explicit Google account linking.
- Host-only sessions and expiring one-time browser login handoff for each app.
- Utility tools, QR image, document converter, URL shortening, private/public code snippets, project Lab, API keys and Docs.
- Administrator QR/PDF verification registry with drag/drop positioning, private original/output and revoke.
- Public validation portal shows issuer & time, PDF hash and local hash comparison.

Limitations: cannot claim legal qualified e-signature; DOCX/Office converter disabled for upload safety; install dependencies and configure Google/Hostinger credentials on own VPS before integration testing.
