# Febro Ecosystem — Design direction

- Identity: practical independent maker/developer workspace. No fake activity, counters, testimonials, decorative terminal.
- Visual language: flat, light blue accents, warm white/near-black dark. Crisp typography with system fonts. Narrow content widths and functional information architecture.
- Motion: restrained; hover and focus only, support reduced motion.
- Desktop/mobile: use adaptive nav, responsive grid, readable code tables and touch-capable QR positioning.
- Each app prominently attributes "by Febro Herdyanto".
- Copy: plain Indonesian, names of real features and honest prerequisites. No decorative glow/gradient hero or invented testimonials.
- Design review references: https://github.com/miqdadbadjuber/anti-slop
